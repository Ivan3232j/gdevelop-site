# Топдаун Шутер · Урок 2: Стрельба и снаряды

Nov 24, 2026 · @Иван Денисов

## Цель и подготовка

К концу урока танк или боец каждого ребёнка стреляет снарядами по клику и при зажатии левой кнопки мыши. Пули вылетают строго из дула оружия, летят в сторону прицела с заданной скоростью и автоматически удаляются за границами видимости, не перегружая память компьютера.

**Главная идея урока для детей:** Пуля — самостоятельный объект. Игрок только создаёт её в точке дула и даёт начальный импульс, дальше она живёт по своим законам физики.

**Новые понятия:** пользовательские точки спрайта (Custom Points), создание объекта в координатах точки `Player.PointX("Gun")`, постоянная сила под углом (Add force / Angle), событие «В начале сцены», таймер скорострельности (Cooldown), поведение «Уничтожить за пределами экрана».

**Подготовить заранее:**

- [ ] Проекты детей с урока 1 открываются, персонаж движется и целится за мышью
- [ ] Эталон урока 2 с работающей стрельбой для демонстрации
- [ ] Запасной спрайт пули для тех, кто задержится на рисовании
- [ ] Нарисовать на доске дуло и объяснить, почему пуля, созданная из центра спрайта, выглядит криво

## Тайминг 90 минут

| Время | Блок | Что делают дети |
| --- | --- | --- |
| 0–10 | Вход | Запускают эталон, стреляют. Обсуждают: почему пули не должны вылетать 60 раз в секунду? |
| 10–25 | Рисуем пулю и дуло | Спрайт пули в Piskel + добавление точки `Gun` на ствол игрока |
| 25–50 | Механика выстрела | Событие клика, создание пули в точке дула, придание импульса под углом |
| 50–70 | Скорострельность | Таймер кулдауна: превращаем «лазерную стену» в автоматную очередь |
| 70–85 | Оптимизация и тест | Поведение удаления за экраном, проверка через отладчик, доп. задания |
| 85–90 | Итог | Сохраняют проект. Объясняют: зачем нужна точка дула вместо координат X/Y центра? |

## Блок 1. Рисуем пулю и настраиваем точку дула (10–25 мин)

Снаряд должен быть заметным на темном фоне, а вылетать он обязан из ствола, а не из «живота» персонажа.

1. **Создание пули:**
   - Добавить объект Sprite с именем `Bullet` и открыть Piskel.
   - Холст **16 × 8 пикселей** (или 16 × 16).
   - Нарисовать светящийся снаряд: ярко-желтый лазер, плазменный сгусток или патрон.
   - **Важно:** снаряд должен смотреть **вправо** (вдоль оси 0°).
   - Точки (Edit points) → убедиться, что **Origin** и **Center** стоят по центру пули.

2. **Точка дула на игроке (Custom Point):**
   - Открыть свойства объекта `Player` → нажать кнопку **Редактировать точки (Edit points)**.
   - Нажать **+ Добавить точку (Add a point)**.
   - Назвать точку строго: `Gun` (с заглавной буквы, без пробелов).
   - Перетащить появившийся маркер на самый кончик ствола (или в дуло пушки).
   - Нажать «Применить». Теперь движок в любой момент знает точные координаты дула, даже когда персонаж крутится во все стороны!

## Блок 2. Механика выстрела и полет пули (25–50 мин)

Выстрел состоит из трех одновременных действий: создать пулю, повернуть её в сторону взгляда игрока и толкнуть вперед.

**Событие 1 — Базовый выстрел:**

| Условие | Действия по порядку |
| --- | --- |
| Кнопка мыши нажата или касание *(Mouse button pressed or touch held: Left)* | 1. Создать объект `Bullet` в позиции X: `Player.PointX("Gun")`, Y: `Player.PointY("Gun")` |
|  | 2. Изменить угол `Bullet`: установить в `Player.Angle()` |
|  | 3. Добавить объекту `Bullet` постоянную силу под углом: угол `Player.Angle()`, скорость `800` пикс/сек |

**Разбор для детей:**
- `Player.PointX("Gun")` и `Player.PointY("Gun")` — это математические радары, которые вычисляют координаты нашей созданной точки с учётом текущего поворота тела игрока.
- Действие 2: поворачиваем саму пулю, чтобы вытянутый снаряд летел носом вперед, а не боком.
- Действие 3: «Постоянная сила» (Permanent force) заставляет пулю нестись по прямой до тех пор, пока мы её не остановим или не удалим.

**Объяснение Object Picking (Выбор объектов):** спросите детей — на сцене уже 50 пуль, почему действия 2 и 3 не поворачивают и не толкают их все? Потому что сразу после действия «Создать объект» GDevelop **выбирает только что созданную пулю**. Все следующие действия с `Bullet` в этом событии относятся только к ней. Старые пули продолжают лететь, как летели.

**Мини-эксперимент (3 минуты):** запустите игру и зажмите левую кнопку мыши. Что произошло? Пули вылетают каждый кадр — получается сплошная светящаяся полоса из сотен пуль, а игра начинает притормаживать. Спросите детей: как в реальном оружии устроен интервал между выстрелами?

## Блок 3. Скорострельность и задержка (50–70 мин)

Чтобы контролировать темп стрельбы, мы используем встроенный таймер сцены (секундомер).

1. Создать **новое событие** с условием **В начале сцены (At the beginning of the scene)** — на уроке 1 такого события ещё не было. Добавить в него действие: **Запустить (сбросить) таймер сцены (Start (or reset) a scene timer)** с именем `"FireRate"`.
   *(Строго говоря, GDevelop сам заведёт таймер при первой проверке, но явный запуск приучает к порядку: все «стартовые настройки» живут в одном событии. На следующих уроках мы будем дописывать в него новые действия.)*
   **Важно:** событие «В начале сцены» должно стоять **отдельно, на верхнем уровне**. Событие выстрела не вкладываем в него как подсобытие, иначе стрельба сработает один раз за всю игру.
2. Переписать событие выстрела — теперь выстрел происходит только если прошло достаточно времени:

| Условия | Действия по порядку |
| --- | --- |
| Кнопка мыши нажата (Left) | 1. Создать объект `Bullet` в X: `Player.PointX("Gun")`, Y: `Player.PointY("Gun")` |
| **+** Значение таймера сцены `"FireRate"` ≥ `0.2` секунд | 2. Изменить угол `Bullet`: установить в `Player.Angle()` |
|  | 3. Добавить объекту `Bullet` силу: угол `Player.Angle()`, скорость `800` |
|  | 4. **Сбросить таймер сцены с именем `"FireRate"`** |

**Почему это работает:** 
0.2 секунды — это 5 выстрелов в секунду (отличный темп для штурмовой винтовки). Пока не прошло 0.2 с, условие таймера ложно, и новые пули не создаются. Как только время прошло, событие создаёт ровно одну пулю и тут же обнуляет секундомер!

**Мини-эксперимент (2 минуты):** временно отключите действие «Сбросить таймер» (правый клик → Отключить). Через 0.2 секунды после старта снова появится сплошная полоса: секундомер больше не обнуляется, и условие «прошло ≥ 0.2 с» остаётся истинным навсегда. Включите действие обратно.

## Блок 4. Очистка памяти и отладчик (70–85 мин)

Каждая выпущенная пуля летит бесконечно. Если выпустить 500 пуль, они улетят на миллионы пикселей, но процессор продолжит вычислять их координаты.

1. Открыть свойства объекта `Bullet` → вкладка **Поведения (Behaviors)**.
2. Добавить поведение **«Уничтожить за пределами экрана» (Destroy outside screen)**.
3. В параметре «Extra border» оставить 50–100 пикселей (пуля удаляется, когда отлетит на это расстояние за край экрана).
4. **Проверка в отладчике:**
   - Запустить превью игры через Отладчик (кнопка с жуком рядом с Play).
   - Встать в центре и выпустить очередь из 20 пуль.
   - В отладчике открыть список экземпляров (Instances) сцены: количество `Bullet` сначала растёт, а затем, когда пули улетают за край экрана, возвращается к нулю!

**Мини-эксперимент (2 минуты):** уберите галочку с поведения (или удалите его), постреляйте 10 секунд и снова загляните в отладчик. Сотни «невидимых» пуль продолжают жить где-то далеко за экраном. Верните поведение.

## Частые ошибки и быстрые решения

| Что видит ребёнок | Причина | Решение |
| --- | --- | --- |
| Пуля появляется не из ствола, а сбоку или сзади | Точка `Gun` смещена или названа с ошибкой | Проверить название точки в кавычках `"Gun"` и её положение в Edit points |
| Пуля летит боком | Картинка снаряда в Piskel нарисована вверх или вниз | Повернуть спрайт пули в Piskel строго носом вправо |
| Сплошной непрерывный лазер вместо пуль | Забыли действие «Сбросить таймер "FireRate"» **или** имена таймера в условии и в сбросе отличаются | Добавить сброс таймера последним действием; проверить регистр букв: `"FireRate"` и `"firerate"` — это два разных таймера |
| Выстрел срабатывает один раз за игру или не срабатывает вообще | Событие выстрела оказалось подсобытием «В начале сцены» | Перетащить событие выстрела на верхний уровень (влево, без отступа) |
| Пули застревают на месте и не летят | Выбрана «Мгновенная сила» (Instant) вместо «Постоянной» (Permanent) | В действии «Добавить силу» переключить режим на постоянную силу |
| Пули летят, но не туда, куда смотрит игрок | В силе указан угол `Bullet.Angle()` до поворота пули или число `0` | Угол силы — `Player.Angle()` |
| В отладчике количество `Bullet` растёт и не уменьшается | Поведение Destroy outside screen добавлено не тому объекту (например, `Player`) | Удалить поведение у `Player` и добавить его объекту `Bullet` |

## Проверка результата и задания для быстрых

**Урок пройден, если у ребёнка:**

- [ ] При клике мышью пуля рождается точно на кончике дула
- [ ] Пули летят в ту сторону, куда смотрит персонаж, с одинаковой скоростью
- [ ] Оружие имеет комфортный темп стрельбы (нет пулемётного лага)
- [ ] Улетающие за экран пули удаляются и не захламляют игру

**Задания для быстрых (по сложности):**

1. **Смена оружия:** Объявить переменную сцены `FireDelay` (Число, значение `0.2`): Сцена → **Переменные сцены (Scene variables)** → Добавить. *В новых версиях GDevelop переменную нужно сначала объявить, иначе событие подсветится ошибкой.* Подставить `FireDelay` в условие таймера вместо числа `0.2`. Добавить события: клавиша `1` → `FireDelay` = `0.5` (пистолет), клавиша `2` → `FireDelay` = `0.08` (миниган).
2. **Разброс пуль (Spread):** В действие приложения силы подставить угол со случайным отклонением: `Player.Angle() + RandomInRange(-6, 6)`. Стрельба станет реалистичной и живой. *(Чтобы пуля и летела, и смотрела в одну сторону, сначала задайте случайный угол самой пуле, а в силе используйте `Bullet.Angle()`.)*
3. **Дробовик (Shotgun):** Отдельное событие на правую кнопку мыши со своим таймером `"ShotgunReload"` ≥ `0.8` с. В нём три раза подряд повторить связку из трёх действий: «Создать `Bullet` → угол `Bullet` → сила», меняя угол: `Player.Angle() - 15`, `Player.Angle()`, `Player.Angle() + 15`. Каждое «Создать объект» выбирает новую пулю, поэтому следующие два действия относятся именно к ней. В конце — сбросить `"ShotgunReload"`.
4. **Отдача при выстреле:** В событие выстрела добавить игроку **мгновенную** силу под углом `Player.Angle() + 180` со скоростью около `1500`. Мгновенная сила действует всего 1 кадр, поэтому скорость нужна большая: при `150` игрок сдвинется на 2–3 пикселя, и этого никто не заметит. Подберите число, при котором отдача ощущается, но не мешает играть.
