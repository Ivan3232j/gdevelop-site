# 🕹️ GDevelop Академия — Сайт курса по разработке игр

Интерактивный сайт с поурочными планами и методическими материалами курса разработки 2D-игр на движке **GDevelop 5** для детей и подростков.

**Автор курса:** Иван Денисов  
**Движок:** GDevelop 5 (Desktop App) + Piskel + jfxr

---

## 🚀 Возможности сайта для учеников и преподавателя

1. **100% сохранение авторских материалов**: все формулы, таблицы условий и действий, тайминги, педагогические советы и ссылки на документацию сохранены в первозданном виде.
2. **Интерактивные чек-листы (`localStorage`)**: в конце каждого урока ученик может отмечать выполненные пункты («Урок пройден, если у ребёнка...»). При успешном завершении всех критериев урока запускается праздничный салют конфетти 🎉.
3. **Интерактивный таймлайн 90 минут**: визуальная диаграмма распределения времени (Вход → Рисование → Механика → Логика → Проверка → Итог) с быстрым переходом к нужному блоку.
4. **Специальная стилизация таблиц событий GDevelop**: условия подсвечены голубым (`⚡ Условие`), действия — индиго (`▶ Действие`).
5. **Копирование формул в один клик**: любое математическое выражение или функция (`TimeDelta()`, `clamp()`, `RandomInRange()`, координаты полос) копируются по клику без риска опечаток.
6. **База скорой помощи (85 частых ошибок)**: единый справочник со всеми типовыми ошибками из обоих модулей с мгновенным поиском по симптомам («размытый персонаж», «двойной урон», «отладчик», «хитбокс»).
7. **Глобальный поиск (`⌘K` / `Ctrl+K`)**: быстрый поиск по всем урокам, механикам и ошибкам.
8. **Тёмная и светлая темы**: интерфейс адаптирован как под стиль современного игрового движка, так и под дневное чтение.
9. **Готовность к печати (`@media print`)**: по кнопке «Распечатать» любой урок выводится на печать в чистом компактном формате без меню и интерфейсного мусора.
10. **Полная автономность (Zero Dependencies)**: работает прямо из браузера (даже без интернета) и идеально подходит для GitHub Pages.

## 📚 Содержание курса

### 🏃 Модуль 2: 2D Раннер (Subway Surfers стиль)
- **Урок 1: Бесконечная дорога и три полосы** (Tiled Sprite, `TimeDelta()`, иллюзия движения, Tween переходов).
- **Урок 2: Препятствия** (Таймеры сцены, `RandomInRange(1, 3)`, генерация барьеров, удаление за экраном).
- **Урок 3: Монеты, счёт и рекорд** (Сбор монет, группы объектов, работа со Storage, сохранение рекорда).
- **Урок 4: Прыжок, проигрыш и ускорение** (Механика прыжка, настройка хитбоксов, экран Game Over, нарастание скорости).
- **Урок 5: Сочность и публикация** (Эмиттер искр, звуки jfxr, мигание экрана, релиз на gd.games, плейтест).

### 🎯 Модуль 3: Топдаун Шутер
- **Урок 1: Движение, прицеливание и камера** (Top-Down Movement, поворот на курсор, слежение камеры).
- **Урок 2: Стрельба и снаряды** (Точка Muzzle, угол выстрела, скорострельность, очистка памяти).
- **Урок 3: Враги и здоровье** (ИИ преследования, поведение Health, спавнер волн, урон от пуль).
- **Урок 4: Интерфейс, урон и Game Over** (Слой интерфейса UI, полоска здоровья, контактный урон, перезапуск).
- **Урок 5: Сочность, спецэффекты и публикация** (Эмиттер взрывов, Camera Shake, звуки, релиз на gd.games).

### 📘 Методология
- **Стандарт и методология разработки курсов** (Философия «Всё создаём сами», Zero External Assets, стек Piskel + jfxr, канонический шаблон).

## 🌐 Как опубликовать сайт на GitHub Pages

Сайт полностью статичен и запускается прямо из корня репозитория:

1. Инициализируйте Git (если репозиторий ещё не создан):
   ```bash
   git init
   git add -A
   git commit -m "Первоначальный релиз сайта курса GDevelop"
   ```

2. Создайте репозиторий на GitHub (например, `gdevelop-site`) и подключите его:
   ```bash
   git remote add origin https://github.com/ВАШ_АККАУНТ/gdevelop-site.git
   git branch -M main
   git push -u origin main
   ```

3. В настройках репозитория на GitHub:
   - Перейдите в **Settings** → **Pages**
   - В разделе **Build and deployment** выберите:
     - **Source**: `Deploy from a branch`
     - **Branch**: `main`, папка `/ (root)`
   - Нажмите **Save**.

Сайт будет доступен по адресу:
`https://ВАШ_АККАУНТ.github.io/gdevelop-site/`

## 🛠️ Как обновлять уроки

1. Редактируйте файлы уроков в папке `lessons/` (или добавьте новые).
2. Запустите скрипт обновления данных:
   ```bash
   ./deploy.sh
   ```
   Скрипт автоматически обновит `js/lessons-data.js` без потери структуры.
3. Отправьте изменения в Git:
   ```bash
   git add -A && git commit -m "Обновление уроков" && git push
   ```
