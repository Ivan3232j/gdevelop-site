# Топдаун Шутер · Урок 4: Интерфейс, урон и Game Over

Dec 8, 2026 · @Иван Денисов

## Цель и подготовка

К концу урока в игре появляется полноценный интерфейс выживания: полоска здоровья и счёт в углу экрана, которые не улетают вместе с камерой, система получения урона от касания монстров с окном неуязвимости, а также экран проигрыша (Game Over) с возможностью перезапустить раунд.

**Главная идея урока для детей:** Интерфейс (HUD) живёт в «своём измерении» — на отдельном слое UI. Камера может летать по гигантской карте, но жизни и счёт всегда остаются прибитыми к углам экрана.

**Новые понятия:** слой интерфейса (`UI Layer`), поведение `Anchor` (Якорь), шкала ресурса (`Resource bar`), окно неуязвимости игрока (i-frames, `Damage cooldown`), масштаб времени (`Time scale`), перезапуск сцены, переменная счёта `Score`.

**Подготовить заранее:**

- [ ] Проекты детей с урока 3: враги преследуют игрока и получают урон от пуль
- [ ] Эталон урока 4 с рабочим интерфейсом и экраном поражения
- [ ] Нарисовать на доске слои: «Слой мира» (внизу, летает камера) и «Слой UI» (стекло монитора поверх мира)

## Блок 1. Слой интерфейса и полоска здоровья (10–30 мин)

Если просто положить объект на сцену, камера отцентрируется на персонаже и уедет, оставив жизни где-то на старте. Решение — отдельный слой UI.

1. **Создание слоя:**
   - В правом верхнем углу редактора сцены открыть панель **Слои (Layers)**.
   - Нажать кнопку **Добавить слой (Add layer)** и назвать его строго: `UI`.
   - *Важно:* слой `UI` должен стоять **выше** в списке, чем `Base layer` (Основной слой).

2. **Создание шкалы здоровья:**
   - Добавить новый объект → в поиске набрать `bar` → выбрать **Шкалу ресурса (Resource bar, continuous)** из раздела интерфейса. Назвать `HealthBar`.
   - Максимальное значение (Max value) шкалы по умолчанию = `100` — как раз столько жизней будет у игрока.
   - Перетащить шкалу на сцену и в свойствах экземпляра выбрать слой: **`UI`** (вместо Base layer). *Проще всего: сначала выделить слой `UI` в панели слоёв, а потом перетаскивать объекты — они сразу лягут на него.*
   - Поместить шкалу в левый верхний угол экрана (например, X = 30, Y = 30).

3. **Поведение Якорь (Anchor):**
   - Открыть свойства объекта `HealthBar` → вкладка **Поведения (Behaviors)** → Добавить поведение **Якорь (Anchor)**.
   - Left edge → **Window left**, Top edge → **Window top**.
   - Слой `UI` уже держит шкалу на месте, когда едет камера. Якорь нужен для другого: чтобы шкала осталась в углу, если игру откроют в окне другого размера (например, во весь экран на gd.games).

**Мини-эксперимент (2 минуты):** переложите `HealthBar` на `Base layer` и проедьте по карте. Шкала останется лежать на земле в точке старта. Верните её на `UI`.

## Блок 2. Здоровье игрока и контактный урон (30–55 мин)

Враги теперь не просто бегают за игроком — они атакуют его при сближении.

1. **Поведение Health игроку:**
   - Открыть свойства объекта `Player` → вкладка **Поведения**.
   - Добавить поведение **Health**: Starting health = `100`, Maximum health = `100`.
   - **Damage cooldown (Перезарядка урона) = `0.8`** — это и есть окно неуязвимости. После удара игрок 0.8 секунды не получает новый урон.

2. **Связка шкалы с жизнями игрока:**
   - В событии без условий (каждый кадр) добавить действие:
   - Выбрать `HealthBar` → Изменить значение (Value) → установить в: `Player.Health::Health()`.
   - Теперь полоска на лету отображает реальные жизни танка!

3. **Контактный урон:**

| Условия | Действия по порядку |
| --- | --- |
| `Enemy` касается (Collision) с `Player` | 1. `Player` → **Нанести урон (Apply damage to an object)**: `20` |

**Почему окно неуязвимости жизненно необходимо:**
Спросите детей: игра работает с частотой 60 кадров в секунду. Если зомби касается игрока, событие срабатывает **каждый кадр**. За сколько игрок потеряет 100 HP при уроне 20 за кадр?
*Ответ:* ровно за 5 кадров (меньше 0.1 секунды!). Игрок умрёт моментально. Damage cooldown 0.8 с даёт игроку «окно неуязвимости», чтобы среагировать и отбежать: поведение Health просто игнорирует урон, пока окно открыто.

**Мини-эксперимент (2 минуты):** поставьте Damage cooldown = `0` и дайте зомби себя коснуться. Мгновенная смерть! Верните `0.8`.

4. **Игрок краснеет, пока неуязвим** — два отдельных события **верхнего уровня** (не подсобытия!):

| Условие | Действие |
| --- | --- |
| `Player` → **Is damage cooldown active** (Перезарядка урона активна) | Изменить оттенок (Tint) `Player`: `255;100;100` |
| **НЕ** `Player` → Is damage cooldown active *(правый клик по условию → Инвертировать)* | Изменить оттенок `Player`: `255;255;255` |

*Как объяснить детям:* красный цвет — это «щит включён». Пока щит горит, зомби не может укусить.

## Блок 3. Поражение: экран Game Over (55–75 мин)

Когда жизни падают до нуля, игрок погибает, а на экране появляется меню окончания игры.

1. **Создание баннера Game Over:**
   - Создать текстовый объект `TextGameOver` с крупной надписью **«GAME OVER»** (красный цвет, крупный шрифт 64).
   - Поместить его по центру экрана на слой **`UI`**.
   - Создать второй текстовый объект `TextRestart` с надписью «Нажмите R для перезапуска».
   - В событии «В начале сцены» скрыть оба текста (действие **Скрыть объект**).

2. **Событие гибели:**

| Условие | Действия по порядку |
| --- | --- |
| Объект `Player` мёртв (Is dead) | 1. Показать объект `TextGameOver` |
|  | 2. Показать объект `TextRestart` |
|  | 3. Удалить объект `Player` |
|  | 4. Изменить масштаб времени сцены (Time scale): установить в `0` *(пауза всего мира)* |

**Что такое Time scale = 0:**
Это режим полной остановки времени в игре. Монстры замирают на месте, пули останавливаются в воздухе, таймеры спавна не тикают. Но события продолжают проверяться каждый кадр — поэтому клавиша R для рестарта всё ещё работает!

## Блок 4. Перезапуск и счёт (75–85 мин)

**Событие рестарта:**

| Условия | Действия по порядку |
| --- | --- |
| Клавиша `r` нажата | Сменить сцену (Change the scene) → выбрать **текущую** сцену *(сцена загрузится заново с нуля)* |

*Нужно ли возвращать Time scale в 1?* Нет: масштаб времени свой у каждой сцены, и при перезапуске он сам становится `1`, как и здоровье, враги и таймеры.

**Счёт очков (Score):**

1. Объявить переменную сцены `Score` (Число, `0`): Сцена → **Переменные сцены** → Добавить.
2. Создать текстовый объект `ScoreText` и положить его на слой **`UI`** в правый верхний угол (можно тоже с поведением Anchor: Right edge → Window right, Top edge → Window top).
3. В событие гибели врага из урока 3 (`Enemy` is dead) добавить действие **перед** удалением врага: изменить переменную `Score`: **прибавить (+)** `100`.
4. В событие без условий добавить: изменить текст `ScoreText` на `"Счёт: " + ToString(Score)`.

*Как объяснить детям:* `ToString()` превращает число в буквы. Текст и число — разные типы данных, «склеить» их можно, только если число тоже стало текстом.

## Частые ошибки и быстрые решения

| Что видит ребёнок | Причина | Решение |
| --- | --- | --- |
| Полоска жизней улетела за пределы экрана при старте | Шкала лежит на Base layer, а не на слое UI | В свойствах объекта на сцене выбрать слой `UI` |
| Игрок мгновенно погибает при малейшем касании врага | Damage cooldown у `Player` остался `0` | В поведении Health игрока поставить Damage cooldown = `0.8` |
| Полоска здоровья пустая или не уменьшается | Опечатка в формуле `Player.Health::Health()` | Использовать мастер выражений: выбрать Player → Health → health points |
| Надпись Game Over видна прямо во время игры | Забыли скрыть её в начале сцены | Добавить действие «Скрыть объект» в событие «В начале сцены» |
| Клавиша R ничего не делает | В условии другая клавиша (`R` заглавная, русская `к`) или в Change scene выбрана не та сцена | Выбрать клавишу `r` из списка; в действии выбрать имя текущей сцены |
| Персонаж остается красным навсегда после первого удара | Событие с белым цветом сделано подсобытием или в нём не инвертировано условие | Сделать два отдельных события верхнего уровня; во втором — инвертированное «Is damage cooldown active» |
| Счёт всегда «0» | Очки прибавляются **после** удаления врага или переменная называется `score` | Поставить «Score + 100» выше «Удалить Enemy»; проверить регистр букв `Score` |

## Проверка результата и задания для быстрых

**Урок пройден, если у ребёнка:**

- [ ] Шкала здоровья закреплена в углу экрана и всегда видна при исследовании карты
- [ ] При контакте с врагом отнимается ровно одна порция жизней, персонаж мигает
- [ ] При нулевом здоровье игра встает на паузу и появляется надпись Game Over
- [ ] Клавиша R чисто перезапускает уровень с полным здоровьем
- [ ] Счёт в углу экрана растёт на 100 за каждого убитого врага

**Задания для быстрых (по сложности):**

1. **Время выживания:** Добавить на слой `UI` текст `TimeText`. В «Начале сцены» запустить таймер `"Survive"`, а каждый кадр выводить `"Время: " + ToString(floor(TimerElapsedTime("Survive")))`. При Game Over время замрёт само (Time scale = 0).
2. **Аптечка (Medkit):** Нарисовать спрайт сердечка `Heart`. В событии смерти врага добавить подсобытие с условием `Random(100) < 20` (шанс ~20%) → создать `Heart` в точке `Enemy.X()`, `Enemy.Y()`. Новое событие: `Player` касается `Heart` → `Player` → **Heal object**: `30` и удалить `Heart`.
3. **Кнопка мышью:** Нарисовать спрайт-кнопку `RestartButton` на слое `UI` (скрыть в начале сцены, показывать при Game Over). Событие: «Курсор над объектом `RestartButton`» + «Кнопка мыши отпущена» → перезапустить сцену.
4. **Мигание неуязвимости:** Вместо постоянного красного цвета заставить игрока мигать, пока активна неуязвимость: в первом событии с «Is damage cooldown active» менять прозрачность `Player` на `mod(floor(TimeFromStart() * 10), 2) * 155 + 100`, а во втором (инвертированном) возвращать `255`.
